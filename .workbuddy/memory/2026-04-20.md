## EVEMon 国服适配问题修复（第二批）

### 1. ESI is not accessible（SerenDataLoader 失败）
- **原因**：`CheckEsiAvailabilityAsync` 使用 `/v1/status/` 端点，该端点在网易服务器上超时（不支持）
- **修复**：改为 `/v1/universe/categories/`，该端点稳定可用（200 OK）
- 文件：`ESISdeDownloader.cs` → `CheckEsiAvailabilityAsync()`

### 2. 技能队列（SkillQueue）查询失败
- **根因**：`APIProvider.GetESIUrl()` 构建 URL 时：
  1. 使用 `Path.Combine()` 拼接 URL 路径（Windows 会引入反斜杠）
  2. **没有添加 `datasource=serenity` 查询参数**（网易 ESI 需要此参数）
- **修复**：重写 `GetESIUrl()`，改为字符串拼接路径，并对 Seren 服务器自动附加 `datasource=serenity`
- 文件：`APIProvider.cs` → `GetESIUrl()`

### 3. 图片加载失败（image.evepc.163.com 返回 HTML）
- **情况**：`image.evepc.163.com` 域名正确，URL 格式也正确
- **实际问题**：**网易图片服务器本身挂了**，返回一个幽默的"Creative crisis"错误 HTML 页面（2001字节）
- 这是服务器端问题，代码层面无法解决
- 影响：角色头像、物品图标等所有图片均无法显示
- EVEMon 代码中已有异常处理（HttpWebClientServiceException），不影响功能运行，只是图片显示空白
- 建议：等网易修复图片服务器，或后续考虑回退显示默认图标

## EVEMon 国服适配问题修复（第五批）- 2026-04-20 下午

### 技能显示为 Unknown + ComboBox 崩溃
- **症状**：技能队列显示 "Unknown Skill"，SkillSelectControl 抛出 ArgumentOutOfRangeException
- **根因**：`ESISdeDownloader.LoadSkillsFromDatafile` 使用 `XmlSerializer` 直接反序列化 `eve-skills-en-US.xml.gzip`，但该文件包含 XML 命名空间声明（`xmlns:xsi`, `xmlns:xsd`），导致 XmlSerializer 反序列化失败但未抛异常，`SkillGroups` 为空
- **修复**：
  - 使用 `XmlReader.Create()` + `XmlReaderSettings` 禁用命名空间处理：
    ```csharp
    var settings = new System.Xml.XmlReaderSettings { IgnoreWhitespace = true, IgnoreComments = true, IgnoreProcessingInstructions = true };
    using var reader = System.Xml.XmlReader.Create(gzipStream, settings);
    ```
  - 增强调试日志：记录反序列化后的 `SkillGroups` 和 `Skills` 数量
- 文件：`ESISdeDownloader.cs` → `LoadSkillsFromDatafile()`

### ComboBox.SelectedIndex 崩溃
- **根因**：技能列表为空（`SkillGroups.Count = 0`），导致 UI 控件初始化失败
- **触发**：`SkillSelectControl.OnLoad()` 调用 `InitializeFiltersControls()` 时，ComboBox 没有选项但尝试设置 `SelectedIndex = 0`
- **状态**：修复技能加载问题后应自动解决

## EVEMon 国服适配问题修复（第三批）

### 1. ESI SDE 下载数据格式错误（JSON 解析失败）
- **根因**：`ESISdeDownloader` 假设 `/v1/universe/categories/` 等端点返回**对象数组**，而实际 ESI 返回 **ID 整数数组**（如 `[0, 25, 2100, ...]`）
- **真正 ESI 模式**：先获取 ID 列表，再逐个调用 `/v1/universe/categories/{id}/` 获取详情
- **修复**：`SdeEndpoint` 新增 `DetailPath` 字段，`DownloadEndpointWithPaginationAsync` 改为两阶段下载，并发度 20

### 2. ESIToDatafileConverter 数据模型字段错误
- **EsiGroup**：ESI 实际字段是 `types: List<int>`（不是 type_ids）
- **EsiMarketGroup**：ESI 实际字段只有 `{ market_group_id, name, description, types }`，**无** `parent_group_id`，无法构建层级
- **修复**：更新数据模型，ConvertItems 改为扁平化 market group 列表；删除废弃方法

### 3. CitadelStation 无限循环（程序卡死）
- **根因**：Seren 服务器跳过 citadel 查询时，未调用 `info.OnRequestStart(esiKey)`，导致 `RequestAttempted()` 永远返回 false，同一 ID 无限重新入队
- **修复**：在 Seren 跳过分支中先调用 `OnRequestStart(esiKey)` 再调用 `OnRequestComplete(null)`
- 文件：`EveIDToStation.cs` → `CitadelStationProvider.FetchIDs()`
